Building a question file

A question file is a plain .json file. Here's the shape it needs — image, topic and explanation are all optional.

{
  "title": "Sample Practice Set",
  "instantFeedback": true,
  "questions": [
    {
      "topic": "Geography",
      "question": "What is the capital of Japan?",
      "choices": [
        { "text": "Osaka", "explanation": "Not quite — Osaka is Japan's second-largest city." },
        { "text": "Tokyo", "explanation": "Correct — Tokyo became the capital in 1868." },
        { "text": "Kyoto", "explanation": "Not quite — Kyoto was the capital before 1868." }
      ],
      "correctIndex": 1,
      "explanation": "Tokyo became the capital in 1868."
    },
    {
      "question": "Which shape is shown?",
      "image": "https://example.com/shape.png",
      "choices": [
        { "text": "Triangle", "image": "data:image/svg+xml;utf8,..." },
        { "text": "Square" }
      ],
      "correctIndex": 0
    }
  ]
}

Images can be a normal web link (https://...) or an embedded file (a data:image/...;base64,... string), on a question, a choice, both, or neither.

Instant feedback: set top-level "instantFeedback": true to reveal correct/incorrect and any explanations right after each answer, instead of only at the end. Leave it off (or omit it) to only show the review at the end. Any question can override the quiz's setting with its own "instantFeedback" value.

Explanations: add "explanation" text to a choice to explain that specific option — shown under it once revealed, with a "See more" toggle if it runs long. A question-level "explanation" is used as a fallback under the correct choice when choices don't have their own, and is always shown in the end-of-test review.
