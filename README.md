# Practice Set — Multiple Choice Practice & Test App

A single self-contained web app for multiple-choice practice tests. Works on desktop and mobile, in any browser. No install, no build step — it's one HTML file.

## Opening it

Double-click `practice-set.html`, or upload it to any web host (or drag it into Google Drive / Dropbox and share the link). There is nothing to build or install.

## What it does

- Opens on the line **"The Best Way To Learn Is Practice."**
- Loads a question set from a `.json` file you provide (or the built-in sample set)
- Runs a multiple-choice test: one question at a time, progress bar, jump-to-question dots, timer
- Questions and/or answer choices can each optionally include an image
- At the end, shows:
  - A basic summary — score, time, accuracy by topic, and a full right/wrong review with explanations (works completely offline, no cost)
  - Optional **AI study notes** — a short, personalized write-up of strengths and what to focus on next, generated by Claude

## The question file format

A question file is plain JSON. Only `question`, `choices`, and `correctIndex` are required — `image`, `topic`, and `explanation` are optional.

```json
{
  "title": "Sample Practice Set",
  "instantFeedback": true,
  "questions": [
    {
      "topic": "Geography",
      "question": "What is the capital of Japan?",
      "choices": [
        { "text": "Osaka", "explanation": "Not quite — Osaka is Japan's second-largest city." },
        { "text": "Tokyo", "explanation": "Correct — Tokyo became the capital in 1868." },
        { "text": "Kyoto", "explanation": "Not quite — Kyoto was the capital before 1868." }
      ],
      "correctIndex": 1,
      "explanation": "Tokyo became the capital in 1868."
    },
    {
      "question": "Which shape is shown?",
      "image": "https://example.com/shape.png",
      "choices": [
        { "text": "Triangle", "image": "data:image/svg+xml;utf8,..." },
        { "text": "Square" }
      ],
      "correctIndex": 0
    }
  ]
}
```

Notes:
- `image` fields (on a question or a choice) accept **either** a normal web link (`https://...`) **or** an embedded image (a `data:image/png;base64,...` string). Use a link if the image is already hosted somewhere; embed it if you want the question file to be fully self-contained with no outside dependency.
- `topic` is optional and drives the "accuracy by topic" breakdown on the results screen — leave it off if you don't need that.
- `instantFeedback` (optional, top-level, `true`/`false`) controls whether the app reveals correct/incorrect and any explanations right after each answer, instead of waiting until the end. Leave it off, or omit it, to only show the review at the finish screen. Any individual question can override the quiz's default by setting its own `"instantFeedback"` — so a single file can mix instant-feedback questions with save-it-for-the-end ones.
- `explanation` can go on a **choice** (explaining that specific option) and/or on the **question** (a general explanation, used as a fallback under the correct choice when no choice has its own, and always shown in the end-of-test review). Explanations over ~140 characters automatically get a "See more" / "See less" toggle so long rationale doesn't crowd the screen.
- People can build these files by hand, or generate them with a spreadsheet-to-JSON script, or ask an AI assistant to convert their notes into this format.
- The app validates the file on load and gives a specific error (e.g. "Question 4 is missing 'correctIndex'") instead of failing silently.

There's a "Download sample file" button in the app itself, and a "?" help panel with this same reference.

## About the AI study notes feature

The AI notes button calls Claude's API directly from the browser. That works out of the box when the app is opened as a Claude.ai artifact or through Claude in an environment that proxies the request for you.

**If you host this file on your own website for other people to use**, that direct browser call won't work securely — API keys should never be embedded in client-side code that anyone can view. To keep the AI feature working after you distribute or sell the app, put a small backend in front of it:

1. Build a tiny server endpoint (a few lines on any free serverless platform) that holds your Anthropic API key and forwards the request to `https://api.anthropic.com/v1/messages`.
2. In `practice-set.html`, find the `fetch('https://api.anthropic.com/v1/messages', ...)` call inside `requestAiSummary()` and point it at your own endpoint instead.

Without that step, the basic (non-AI) summary and full answer review still work completely — the app just shows a friendly message explaining the AI notes aren't connected yet.

## Rebranding / white-labeling

Everything you'd want to change to resell this under your own name is in one place:

- Colors, fonts: the `:root { --paper: ...; --ink: ...; }` block at the top of the `<style>` section
- App name: the `APP_NAME` constant near the top of the `<script>` section
- Opening quote: the `<h1 class="quote">` line in the cover screen HTML
